# 成长星球 · 完整版

这是可长期直接使用的完整版本。

功能：
- 德语 1–4 年级分级词卡、发音、冠词自测、拼写和错题本
- 数学基础、进阶和混合运算
- 中文生字、部首、组词、古诗和阅读记录
- 网球、游泳、跳绳、俯卧撑、仰卧起坐、家务记录
- 网球技能树、比赛、奖牌和游泳成绩
- 原创伙伴收集、升级和解锁
- 每日任务、等级、经验、连续签到
- 星星商城和自定义家庭奖励
- 家长新增任务
- 成就徽章和成长报告
- 数据导出、导入和本地保存
- 自动兼容旧版 V2 / V2.1 数据

## 更新网站
将本目录中的 5 个文件全部上传到 GitHub 仓库根目录并覆盖旧文件：
- index.html
- manifest.webmanifest
- sw.js
- README.md
- .nojekyll

GitHub Pages 会自动重新部署。
